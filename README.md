# CookieLab

Pequeña web educativa que usa cookies del navegador para recordar el nombre,
las preferencias de tema e idioma, el número de visitas y la fecha de la visita
anterior. Incluye un panel para cambiar el nombre o borrar los datos y una cookie
de prueba con caducidad de un minuto.

## Ejecutar

Abre la carpeta en VS Code e inicia `index.html` con la extensión **Live Server**.
Las cookies no funcionan correctamente al abrir el archivo directamente con
`file://`.

## Fases

- Proyecto base
- Guardar y recordar el nombre
- Preferencias de tema e idioma
- Contador de visitas
- Panel de control y datos de visita

## Publicar en GitHub Pages

En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**,
elige `main` y la carpeta `/(root)`, y guarda. Cuando termine el despliegue,
GitHub mostrará la URL pública en esa misma sección.
